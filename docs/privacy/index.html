🪩 SERENDIPITY

Privacy Policy

Serendipity is a Chrome extension that modifies Google Search pages to introduce alternate query pivots and optional reduced-personalization search reruns.

What Serendipity does

Serendipity operates on supported Google web pages and adds a user-facing panel that offers adjacent, contrarian, reflective, and random search pivots. It can also optionally re-run a Google search with reduced personalization and optionally auto-inject a remix into exploratory queries.

User data handling

Serendipity does not collect, transmit, sell, or share personal data to a remote server.

What the extension stores

Serendipity stores user preferences locally in Chrome sync storage. This includes:

  • whether the extension is enabled
  • whether reduced-personalization reruns are enabled
  • whether auto-injection is enabled
  • whether the panel is collapsed
  • intensity level
  • enabled remix engines

Where processing happens

All query remixing and page modifications happen locally in the browser.

Permissions used

  • storage: save user preferences
  • tabs: reload the active Google tab after settings changes
  • scripting: reinforce injection on supported Google web pages
  • webNavigation: reapply the extension when Google changes route state
  • https://www.google.com/*: operate on Google Search pages

Unsupported surfaces

Chrome-internal pages such as chrome://contextual-tasks are not scriptable by extensions and are not modified.
